AI 智慧中心 · Vue 3 登录模板预览

打开预览：http://127.0.0.1:5188/
广告标识版：http://127.0.0.1:5188/signage
启动：在本目录运行 npm run dev -- --port 5188
构建：npm run build

这是独立的界面原型，未连接真实登录、短信或密码重置服务。
密码登录：填写任意非空演示账号、密码，可查看验证与加载反馈。
验证码登录：输入格式正确的手机号，点击获取验证码；不会发送短信，演示验证码为 123456。
注册账号：从登录页下方进入，填写账号、至少 8 位密码和确认密码；支持必填、密码长度和一致性校验，不创建真实账号。返回登录会清除密码。
账号和密码不发送到服务器、不持久化。
例外：广告标识版可主动选择“记住账号”，只在当前浏览器保存账号，不保存密码；取消选择后提交有效登录表单会清除保存的账号。
